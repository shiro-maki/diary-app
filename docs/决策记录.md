### 2026-10-25 需求拷问·第一轮（grill，强度：细问）

| # | 结论 | 理由 |
|---|------|------|
| 拷打强度 | 细问 | 单人本地小项目，重点挖取舍，不过度设计 |

### 2026-10-25 需求拷问·第二轮（grill）

| # | 结论 | 理由 |

### 2026-10-25 环境事实核查（影响选型）

- 本机现有 Python **全部不带 tkinter**：WorkBuddy 托管版 3.13.12（ModuleNotFoundError）、PATH 里的 Store 存根、py 启动器均无可用运行时。
- 结论：跑 Tkinter 方案需在 D 盘装 python.org 官方版 CPython（安装器默认包含 tcl/tk）。

### 2026-10-25 技术选型（architect，AQUA 选定方案 B）

| 项目 | 决策 | 理由 |
|------|------|------|
| 总体方案 | **B 定制版**：customtkinter + 标准库，其余自绘 | AQUA 选 B（要现代 UI）；把依赖压到 1 个包，供应链风险接近方案 A |
| GUI 框架 | customtkinter 6.0.0 | PyPI 实测：2026-06-24 发版（活跃维护）、requires_python >=3.7（兼容 3.13）、定位"modern looking GUIs" |
| tkcalendar | **不引入** | PyPI 实测：最新 1.6.1 发布于 2019-12-28，停更近 7 年；月历格用 customtkinter 自绘约 50 行，零风险 |
| matplotlib | 推迟到「统计」功能再做 | v1 无统计需求，不为未来功能提前背 30MB+ 依赖 |
| Python 运行时 | D 盘装 python.org 官方 CPython（拟 `D:\Python`） | 本机现有 Python 全不带 tkinter（已实测）；官方安装器默认含 tcl/tk；避开 C 盘 |
| 启动方式 | `start.bat` 双击启动 | 符合 AQUA 一键脚本习惯；bat 内指定 `D:\Python\python.exe`；按 AQUA 环境规则用 ASCII+CRLF |
